# 47 Skin — What Comes After Cleansing? Your Serum.

A speculative React + Vite Gmail-inspired inbox and email portfolio experience.

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The built application is in `dist/`. For Vercel, import the repository, choose Vite, set build command `npm run build` and output directory `dist`.

## Behaviour

- App opens on the inbox, not the email.
- Only **What comes after cleansing? Your serum.** can be opened.
- Other inbox messages are fictional, non-openable, and intentionally do not claim to be real mail.
- Search, folder navigation, starring, and back-to-inbox work locally. No real mailbox, credentials, or backend.
- The CTA goes to `https://47skin.com/products/anti-blemish-scar-repair-serum`, the product-page URL supplied earlier in this 47 Skin campaign conversation. This specific email draft did not repeat the URL.
- The supplied subject and subheading are treated as email metadata rather than body copy. All supplied paragraphs and signoff appear in full.
